# Lexical query contract (Slice01 proposal)

**Status:** The Slice01 contract was independently accepted at source `49e1d977`; its original proposal wording remains as history. Slice02 supplies a proposed-done local importer/API candidate that realizes selected identity, presence, exact-query, form-role, and cross-reference behaviors; see [the Slice02 model report](lexical-model-import.md). No downstream database or production adoption is implied.

This contract records the finite consumer questions in Arc02 without implementing a local model or deciding source authority. Raw E02 files remain the primary witnesses; replayable indexes are pointers back to those bytes. A missing field means unknown unless a captured source explicitly encodes absence. Never merge records by spelling alone.

## Concrete controls retained

- La `si'e`: `raw/lexical/la-lojban-en.json`, array index 12598, definition ID 2171, `word_type=cmavo`, `selmaho=MOI`. LLG also has a cmavo `si'e` row and a separate assigned rafsi row `si'e → snime`; they are three typed facts, not one spelling-level object. Exact `sie` is a separate query and is absent from the captured La and LLG cmavo exact-field searches.
- LLG fixed-column parsing uses the source-specific reader in `experiments/E02-resource-discovery/scripts/inspect.py`; the phrase `le jaica` is the control showing that splitting the line at whitespace truncates a multiword headword.
- No ELEXIS runtime behavior is asserted because the pinned reference build did not compile. Its `otherForm`, typed POS and extension-retention behavior remain not run.

jbotci’s `exact_definition_indices` method means an attested definition lookup without synthetic/decomposition fallback; it normalizes the query first (including case/diacritic/apostrophe folding and filtering), so it does not satisfy Q01 byte-exact spelling by itself. Keep its useful dictionary/import indexes and add a separate source-string query path if adopted later.

The DMLex and OntoLex mappings are candidate representational affordances only. They do not assert standard conformance, source equivalence, semantic truth, or an adoption choice.
