## Configuration representation and persistence (binding)

One TOML file, separate from catalogue schema1. CLI resolves optional `--config FILE` first without requiring HOME/XDG; otherwise absolute nonempty XDG_CONFIG_HOME/vlajmaji/config.toml, else absolute nonempty HOME/.config/vlajmaji/config.toml. Unset/empty/relative XDG is ignored; unusable HOME yields typed config-path error, no cwd/tmp fallback. Native OsString/PathBuf is retained. Reader never mkdir/downloads or creates default configuration. Explicit relative FILE is frozen against one cwd; all-absolute operations do not require cwd.

Wire version1: required `version=1`, `revision` unsigned, optional `default_profile`, and `[profiles.NAME]` with exactly one `root="..."` or `root_native={encoding="unix-bytes",hex="..."}`, required `packs=[ID,...]`, default `disabled=[]`. Profile names are nonempty ASCII alphanumeric first, then alphanumeric/_/-, maximum64 bytes. Unknown/duplicate fields, duplicate pack IDs, invalid IDs, unknown default profile and unsupported version reject. Empty packs is a truthful no-selection policy, never implicit all. Disabled IDs are separate from default membership; a disabled ID need not be a member but must be a registered known pack when selected/observed. TOML has no null token; omission rules are explicit. Normal Unicode ROOT is the human form; relative textual roots resolve beside the absolute config file, not process cwd. Native alternative is host-tagged lowercase byte hex, nonempty/absolute/NUL-free on Unix; unsupported host encoding errors, never lossy routing. No serialized PathBuf assumption. Writer emits ordinary string for valid Unicode, native form otherwise.

Library explicit-file persistence belongs in new store `collection_profiles.rs`; CLI alone resolves env/default location. Public `CollectionProfiles::read(path) -> Result<Self, CollectionProfileError>` captures exact file bytes/hash/version/revision and typed profiles. `profile(name:Option<&str>)` chooses explicit/default or typed missing/unknown; read-only `report()` emits version/path/revision/hash/default/profiles. `verify_unchanged()` rereads the exact native file and rejects content change. A pure typed `CollectionProfile` contains absolute native ROOT, ordered default PackIds and independent disabled PackIds; validation precedes use. Keep wire DTOs private. Public `CollectionProfiles::configure(path, CollectionProfileWriteRequest)` sets one named profile and optional default, preserving other profiles semantically; request has explicit ROOT/packs/disabled and make_default, no environment lookup. Serialized report names prior/new revision/hash, profile, config native path and committed/unchanged/indeterminate outcome. Initial writer revision1; subsequent checked_add before staging; hand-authored revision0 remains parseable. Exact semantic no-op leaves bytes/revision unchanged, including comments/formatting. Deliberate change may reserialize comments/formatting; document it.

Configure validates args and selected catalogue registrations before creating config parents. `--all` means exactly all four registered IDs, never skip absent/uninstalled/Held. Registered-only selections may be recorded with explicit unavailable state; successful config write does not claim query usability. No installed payload hash/All audit. Freeze ROOT/input bases once; no IO for roots of unselected profiles merely to parse the file. Snapshot selection observes one chosen ROOT only.

Writer protocol: reject symlink/nonregular config leaf and occupied nonfile leaf; benign ancestor aliases are not automatically rejected. Acquire exclusive sibling lock with create_new0600; lock collision typed busy, no stale takeover/delete. Parse/validate old config while locked; retain expected old hash/revision and reject concurrent external change before publication. New parent dirs0700/new files0600; preserve existing parent and existing file permission modes on replacement. Stage is a fresh exclusive sibling file; serialize/write/flush/sync before atomic rename/replace, then sync parent. No overwrite of unrecognized/invalid config. Cooperating writers serialize; noncooperating edits detected optimistically, not a universal filesystem transaction. Explicit cleanup removes only owned lock/stage identities; killed writer may leave identifiable lock/stage, no Drop crash guarantee. Pre-switch failure leaves old config byte-identical; after rename a durably committed config is active even if receipt is lost. Failed directory sync/uncertain IO reports indeterminate with known path/old/new hash/revision and retained stage context; never falsely claims unchanged. Read-only profiles report can reconcile current observed hash. S04 owns recovery/takeover commands, not automatic cleanup here.
