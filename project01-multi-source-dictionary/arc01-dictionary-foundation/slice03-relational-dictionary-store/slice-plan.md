## Capability and preservation boundary

A public caller persists the accepted complete Dictionary to a fresh local store, drops it, opens it read-only and recovers the exact validated model/raw/legacy bytes. Every typed12-area field is independently queryable through concrete SQL columns and ordered child rows. Open rejects incorrect family/schema/completeness/hash/model/FK/schema shape or any relational projection cell/row mismatch. Old SqliteStore/GraphStore/schema1 and their query/archive behavior remain unchanged. This foundation uses one caller-owned directory, not the later topology decision. No grouped query, production editor, automatic normalization/etymology/POS, corpus import/acquisition, package-manager or publication work.

The actual accepted model supplies the types; do not copy/reimplement its validator. Presence, all LocalRef roles, exact strings/number lexemes, known-but-unavailable metadata and immutable history stay as accepted. Stronger store-only grammar/nonempty/ASCII/native-ID inference rules are not authorized. Further readiness evidence is ../artifacts/s03-readiness-notes.md; the binding decisions here supersede its previously unsettled API/name suggestions.

## Public API and errors

Add `DictionaryStore` (private connection/path/validated Dictionary/canonical bytes) in store crate, public exports only in lib.rs. Methods: `create(path:impl AsRef<Path>, dictionary:&Dictionary)->Result<Self,DictionaryStoreError>`, `open(path:impl AsRef<Path>)->Result<Self,DictionaryStoreError>`, `dictionary()->&Dictionary`, `canonical_bytes()->&[u8]`, `path()->&Path`, `database_path()->PathBuf`. `DictionaryStoreError` is a named non-exhaustive public Error with `ExistingPath(PathBuf)`, `InvalidDictionary(DictionaryError)`, `InvalidStore { reason:DictionaryStoreInvalidity, detail:String }`, `Backend(rusqlite::Error)`, `Io(std::io::Error)`. Emit actual variants/reasons at relevant branches, not generic strings/unused vocabulary. from_json invalid canonical model is InvalidDictionary; CanonicalBytes concerns missing/multiple/wrong-shaped blob/hash data. Tests match categories/constraint codes, not only is_err.

The directory contains `dictionary.sqlite3`; metadata format is `vlajmaji-dictionary`, store schema version `1` independent of old SqliteStore schema1 and dictionary JSON version1. Fresh creation refuses any existing destination (including dangling symlinks, via symlink_metadata), validates canonical Dictionary serialization/reload before creating it, then atomically creates only the leaf directory with an already existing parent; do not merge into a concurrently created directory or follow an existing leaf symlink. Parameterize all data and build under a transaction. Create schema/visible metadata complete=false marker first; commit complete=true with all canonical/projection rows. An interrupted/failed own build is rejected, never silently reused/replaced. Do not delete caller/unknown paths. Close writer and return the same readonly validated snapshot as open. Do not build self-referential Connection/Transaction fields or add unsafe. S04 can later add a store-owned indexed candidate method; no lookup API here.

## Concrete schema vocabulary and full field mapping

The following table names/columns and expansion notation bind the logical schema. Private DDL helper organization is discretionary. Actual SQL/field-map docs must expand them transparently and retain all constraints; no generic EAV/typed-object-JSON substitute.

Notation: TEXT is exact BINARY UTF8; BLOB exact bytes; nullable columns preserve Option None versus Some(empty). All vector ordinals are checked nonnegative SQLite INTEGER, unique in their owning vector. u32 uses checked INTEGER 0..4294967295. Full u64/usize values use canonical unsigned decimal TEXT, nullable only for Option, never a lossy i64 cast. Check canonical digits/no leading zeros/range losslessly or rely on exact validated projection with a documented SQL constraint boundary; no float/coercion. Canonical projection must preserve embedded NUL as UTF8 bytes; SQL length(TEXT) is not byte-length (local reference SQLite3.39.4 gave NUL text0/blob1), so avoid invalid stronger emptiness checks or use BLOB byte length. Actual pinned rusqlite controls verify preservation.

`P(x)` expands `x_state TEXT NOT NULL` in missing/null/value and `x_value TEXT NULL`, requiring value non-NULL exactly at state=value, allowing empty string. For Presence<RawJson> the value is its exact raw lexical string. `TP(x)` for Presence<TextValue> expands outer x_state plus nullable x_text/x_language_state/x_language_value/x_markup_state/x_markup_value; all payload columns NULL outside outer value, within value text and both inner states required with their own P consistency. Nonoptional TextValue `TV(x)` has x_text NOT NULL plus P(x_language),P(x_markup). `PM(x)` is Presence<PosMapping>: state plus x_value/x_rule, both supplied exactly when value. No XML/rendering/linguistic inference.

`T(x)` for a LocalRef expands x_kind and nullable x_entry_id/x_assertion_id/x_form_id/x_editorial_sense_id, each direct FK to its role table; exactly the named role's column is present. Required T has non-NULL kind; optional T has all NULL when absent. All four roles allowed for BOTH form and etymology components. `E(x)` expands `x_id INTEGER` as a required/optional FK to source_evidence.evidence_id (thus E(evidence) is evidence_id). Use explicit CHECK predicates with IS NULL/IS NOT NULL; do not let SQL NULL's three-valued logic bypass role/presence constraints. Role tables' id columns FK `(id,entity_role)` to entity_ids with constant role CHECK, preventing a role-table row from masquerading under another entity role. All real FKs enforced and DEFERRABLE INITIALLY DEFERRED where forward references/cycles require; no disabling enforcement.
