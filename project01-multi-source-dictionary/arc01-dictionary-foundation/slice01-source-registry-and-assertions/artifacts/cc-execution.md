## Contract readback

`lib.rs` already makes source bytes, `SnapshotIdentity`, `RecordIdentity`, raw field presence, form roles and proposals distinct; `SourceMetadata::new` accepts and retains empty values. Registry validation therefore belongs in an additive sidecar, never by tightening legacy metadata or changing archive v1/v2. The store's `record_id` is the lowercase hexadecimal encoding of the full byte sequence formed by length-prefixing `(snapshot namespace, snapshot SHA-256, locator)`; it is not a hash. It must remain byte-for-byte unchanged and cannot be reused as registry identity.

The implementation will add three non-interchangeable validated string IDs, public draft records and an invariant-safe `SourceRegistry`. A complete candidate `RegistryDocument` is validated before construction/update; `apply_document` also checks append-only entity, alias, lineage and attribution history before replacing state, so failed operations preserve serialized bytes. Serde deserialization must route through the same validator, and the JSON helper must use the existing duplicate-key scanner. Aliases/selectors are exact-byte and case-sensitive; retired reuse may become ambiguous only under `IncludeRetired`, while active conflicts and ID shadowing fail.

Attribution joins exact snapshot and occurrence identity, never spelling or display names. `validate_lexicon` checks both directions between registered bindings and actual captures; borrowed views require explicit attribution and preserve insertion order/multiplicity. Unknown native IDs remain `None` while supplied empty strings remain `Some("")`. An easily missed failure mode is collapsing the two identical A/D1 rows—or the repeated assertion distributed by D2—because the text or supplied native assertion ID matches. The required oracle is five `farvi` occurrences (A four, B one), including distinct locators, with two distributors of A and conflicting definitions kept separate. Likewise lexical `si'e`/selmaho `MOI` and assigned `si'e -> snime` remain separate source records/forms; no generated `snim`, semantic merge, or proposal-as-capture is allowed.

S01-06 requires shipped docs/example, a real public caller outside the workspace, and Rust 1.98 format/check/test/Clippy/docs plus no-default/all-feature compatibility gates. S01-07 is the independent CDC review, close, and explicit S02/S03 carryover; it remains open until CDC disposition. No schema, store/query, CLI, corpus or publication work is included.
