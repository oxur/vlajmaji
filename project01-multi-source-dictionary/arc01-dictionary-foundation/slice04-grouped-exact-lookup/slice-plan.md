## Selection and exactness

Exact means UTF8 bytes: no case/apostrophe/dot/y/diphthong/phrase/stemming/rafsi normalization. Query EntryRecord.spelling only and Eligibility::Lexical; assigned/computed form spellings do not manufacture lexical entries. Missing definition is still a hit with its original Presence.

DictionaryExactOptions fields: sources:Vec<String> default[], alias_scope:AliasScope defaultActiveOnly, page_size:Option<usize> defaultNone, cursor:Option<String> defaultNone. Strict deny_unknown_fields, serde defaults; explicit null for an Option is None. sources=[] selects all selectable sources. Explicit selectors use the existing SourceRegistry::resolve_source (exact stable ID precedence, exact current abbreviation and eligible aliases), dedup/sort stable SourceIds. Preserve UnknownSource and AmbiguousAlias as nested typed Registry errors. Explicit source with no releases, no selected Available release, or OwnedDraft without a head is UnavailableSource even if spelling has no matches. SourceSelectionFailure enum NoReleases/NoSelectedAvailableRelease/NoOwnedHead; apply that precedence. An available sibling makes the source selectable but all inactive siblings are disclosed. Available-zero is successful zero. Default excludes unselectable sources without concealing their catalogue state.

For each source, union assertions in selected Available releases, dedup by exact occurrence identity; OwnedDraft additionally intersects declared owned head.assertions. Never infer latest vector/head. Then intersect indexed candidates and resolved source selection. Retain distinct raw locators even when text/native tuples match. Full order is SourceId bytes, spelling bytes, existing occurrence-ID tuple-hex bytes. Existing occurrence encoding is NOT a hash. `native_candidate_occurrences` is the number of SQL Lexical exact candidates before source/release/head selection, clearly documented (baseline farvi7); never confuse it with current totals6.

## Pages and strict cursors

None page_size returns the entire remaining suffix, default no cursor is complete. Some0 returns no rows/next_cursor but REAL full totals. Positive sizes page OCCURRENCES, not groups; cap by remaining.len().min(size), no usize overflow. next_cursor exists iff at least one returned row and a further row remains. Changing page size on continuation is allowed. Total/source counts always refer to the complete query before cursor/page. Concatenation of each positive-size traversal must equal the complete ordered reference exactly.

Private cursor DTO strict JSON lowerhex wire: `{body:{version:1,binding:<sha256>,last:{source:<SourceId>,spelling:<String>,occurrence_id:<String>}},checksum:<sha256>}`. Exact field order from deterministic serde serialization; checksum SHA256(serialized body bytes). Binding SHA256 of deterministic typed data containing version1, policy exact-entry-v1, store_schema_version1, canonical state_sha256, exact spelling, sorted resolved_sources, AliasScope and selection_policy='selected-available-owned-head-v1'. page_size/cursor excluded. Reject uppercase/nonhex/odd encoding, nonUTF8, invalidJSON/unknown fields/wrongversion/invaliddigest/checksum as MalformedCursor. After integrity, different binding is StaleCursor. After matching binding, full last key must equal a member of the complete result, else InvalidCursorPosition. Resume strictly after that member; no arbitrary comparison-only acceptance. Full canonical state binds catalogue/heads/names/paths/availability, including advanced catalogue_revision on re-add. This is unkeyed corruption checking, not authentication.

## Stable references: direct request validation and confidence

resolve is independent of current source selectors and includes historical/disabled/removed metadata. Validate arbitrary input, not just model-authored relation targets. CaptureRef conversions are lossless and do NOT validate. LocalRef must exist in its specific role table (Entry/Assertion/Form/EditorialSense), not merely global EntityId. Unknown is valid explicit unknown; Unresolved must be nonempty bytes (NUL is not empty), retained exactly. CatalogTarget source/release must exist and release component/collection must belong to that source. Require native_entry_id or native_assertion_id or occurrence; Some(empty) is a real supplied constraint. Supplied occurrence requires nonempty locator, capture membership in release; if capture loaded, locator must exist. Match validated capture identities rather than adding namespace grammar (legacy empty namespace remains valid). Wrong owner/role, unknown release/source, empty required identities or loaded phantom => InvalidReference. No panic/unwrap on requests.

ReferenceResolution fields: version:u32=1, state_sha256:String, target:RelationTarget echo, status:ReferenceStatus, entity:Option<ReferenceEntity>, confirmed:Vec<ReferenceAssertionView>, unverified:Vec<ReferenceAssertionView>, availability:Vec<DictionarySourceAvailability>, requested_release:Option<ReleaseRecord>. ReferenceStatus enum Resolved/Unverified/CatalogueOnly/NoMatch/Unknown/Unresolved. ReferenceEntity enum Entry(EntryRecord)/Assertion(AssertionRecord)/Form(FormRecord)/EditorialSense(EditorialSenseRecord), corresponding only to a valid local target. availability uses the same complete metadata contract as exact. No HTTP fetch or inferred target substitution.

ReferenceAssertionView { entry:EntryRecord, assertion:AssertionRecord, occurrence_id:String, occurrence_attribution:Option<OccurrenceAttribution>, raw:Option<RawOccurrence>, capture_metadata:Option<CaptureMetadata>, payload_present:bool, current_eligible:bool, release_ids:Vec<EntityId>, owned_revision_ids:Vec<EntityId>, tombstoned_by:Vec<EntityId> }. release_ids includes ALL memberships, not just current. payload_present requires actual capture+locator. current_eligible applies default lookup policy AND lexical eligibility (spelling presence is model-guaranteed for lexical). Views sort global SourceId/spelling/occurrence order, absent spelling sorts empty only for excluded reference records; entity retains original vectors. No raw/capture metadata invented for absent payload.

Local Entry selects its assertions, Assertion itself, Form its entry's assertions, EditorialSense its explicit assertion membership; all go confirmed with statusResolved regardless payload/current state, never silently omit historic metadata. Dedup same assertion identity in repeated editorial membership view but keep entity membership vector. Catalog selects assertions named in the required release, optionally exact occurrence first. For EACH provided native constraint: known unequal excludes; missing attribution/value marks unverified; every known constraint equal and none missing confirms. Native sense ID is never a native assertion substitute. Return all confirmed and unverified, never guess by spelling or path. status Resolved if any confirmed, else Unverified if any unverified, else NoMatch if any base candidates were known mismatches OR release Available; else CatalogueOnly for a nonAvailable release with no assessable rows. A catalogue-only M target retains original request/release and explicit unavailable state. Unknown/Unresolved statuses have empty rows/entity/release. Current selection does not change identity confidence.
