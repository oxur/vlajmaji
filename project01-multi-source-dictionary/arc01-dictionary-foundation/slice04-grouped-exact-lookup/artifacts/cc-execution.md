### Binding design readback

The store change is additive: add `DictionaryStore::exact_assertion_ids(&self, spelling: &str)` using its retained validated read-only SQLite connection, parameter binding, `entries` joined to `assertions`, exact binary spelling and `Lexical` eligibility predicates, and the prescribed source/spelling/occurrence order. It returns checked tuple IDs and maps malformed persisted IDs to `InvalidStore(Projection)` while preserving SQLite failures. No DDL/index/schema or connection exposure changes are allowed; the existing spelling/join indexes must be observed in the query plan.

The search API is an explicitly exported `dictionary` module. Its engine owns a validated store snapshot and association indexes constructed once. Exact matching compares UTF-8 spelling bytes only and never normalizes punctuation, case, apostrophes, y, phrases, rafsi, or computed forms. Candidate count is the indexed SQL count before source/release/head selection. For each selected source, eligible assertions come only from selected Available releases; an OwnedDraft is further intersected with its declared head. Preserve duplicate occurrences and exact tuple-hex ordering. Empty selectors mean all selectable sources; explicit IDs/abbreviations/aliases go through `SourceRegistry::resolve_source`, with stable deduplication and typed unknown/ambiguous failures. Selection failure precedence is no releases, no selected Available release, then no owned head. Available-but-zero is a valid successful empty query.

Responses preserve full totals and per-matching-source totals before paging; availability describes every catalogue source and retains aliases, lineage, collections, components, all releases, loaded/missing capture references, owned head, and reason. A zero-sized page returns no groups/rows but complete totals and no continuation. Groups contain only returned rows and report full/returned/partial counts. The strict page cursor is bound to the canonical state digest and query/filter/source/alias/scope/policy; resizing a page does not invalidate it. Malformed, stale-state, and nonmember/invalid-position cursors remain distinct typed errors. Hits preserve raw occurrence/capture/attribution/native identities and ordered associations across all 12 source, computed, and editorial areas without duplicating full capture bytes.

Reference resolution is a separate checked path for arbitrary `RelationTarget`s. It validates all four LocalRef roles and catalogue source/release ownership, supplied native IDs, and optional occurrence identity. `Some("")` remains supplied data, not absence. Unknown attribution is retained as unverified; mismatches are excluded; unresolved targets are explicit. At least one catalogue identity component is required.
