## Binding package and composition design

Four crates named vlajmaji-data-lensisku-jbotci, vlajmaji-data-llg, vlajmaji-data-la-lojban, vlajmaji-data-sutysisku, all publish=false. Their default feature set is empty. The embedded feature compiles actual release.json and seal.json from ignored/excluded local data/ into the crate using include_bytes!. Umbrella data-lensisku-jbotci/data-llg/data-la-lojban/data-sutysisku enable optional dependency plus embedded. Selected data is actual full normalized content, not a runtime file locator. Missing selected data fails compilation with documented preparation guidance; ordinary default/core/workspace builds need no corpus and never fetch. No build script/network/download. release_bytes()/seal_bytes() borrow static bytes; load() verifies the seal and full model and returns Dictionary. An explicit load is allowed to decode/validate; per-entry lookup must not clone the complete document.

Shared lexicon::pack holds version1 seal (pack_id, payload_kind Synthetic or Full, canonical SHA/length, dictionary/registry versions, ordered source/release/capture inventory), typed errors and pure encode/load/compose helpers. Seal is integrity/accounting, not cryptographic provenance authentication or redistribution authority. Raw versions, normalized model1, pack seal1, normalizer versions, package0.3.0 and SQLite schema1 remain distinct. Release content notices and hold status survive packing.

compose_dictionaries consumes validated models without whole-document cloning. Same-key records deduplicate only if completely equal; differing bodies fail with category/key. Shared SourceRecord identity is one authority, never multiple attestations; distribution captures/occurrences/releases remain distinct. All metadata record classes, registry aliases/lineage/history, exact raw captures, diagnostics/notices and selected/availability semantics survive. Reject legacy_archive-bearing inputs explicitly (no silent archive loss); combine preserves maximum catalogue_revision and first-seen deterministic row ordering, validates resulting registry/model, rejects unequal bodies claiming the same release ID (including selected-state differences), while retaining distinct releases and their selected flags. Empty input returns an empty validated Dictionary. Pure composition does not select storage topology. Distinct native occurrence identities remain even when text agrees.

Explicit CLI data-pack materialize supports each collection as its adapter lands, outputting fresh exclusive directory release.json and seal.json only after successful normalization/sealing. No overwrite/eval/network, no store/default path action, native input paths preserved. Partial I/O output is not a successful seal and is reported honestly; complete files validated before success. Fixture preparation is explicit, emits Synthetic kind and unmistakable fixture capture metadata, never claims real full pin coverage. CI prepares synthetic packs offline before existing Linux --workspace --all-features; does not exclude/disable data features. Hosted target cache can contain only synthetic embedded data; no full corpus cache/artifact upload is added. Local full-data acceptance uses Full seals, exact input hashes and separate receipts.
