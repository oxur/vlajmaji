# vlajmaji
(Re)Lojban dictionaries, schemas, library, and CLI tool

## Research lexical workspace

This repository now hosts a source-preserving lexical envelope, native local
indexes, a reusable query library, and the relojban-search JSON CLI. The
migration provenance, temporary phonology checkout bridge, external corpus
gate, and replay commands are documented in docs/migration.md. The original
repository description above is retained; this code relocation does not make
a license decision for the migrated source.
